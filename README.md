# MOVITA × LinkPrice 제안서

세로 슬라이드형 정적 웹 제안서. 별도 설치와 빌드가 필요 없습니다.

## GitHub Pages 배포
1. ZIP을 해제합니다.
2. `index.html`, `assets/`, `original-proposal.pdf`, `.nojekyll`을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다.
4. GitHub가 표시한 Pages URL을 공유합니다.

## 사용 방법
- 마우스 스크롤 / 터치: 위아래 탐색
- ↑ / ↓ / PageUp / PageDown / Space: 슬라이드 이동
- Home / End: 처음 / 마지막
- 우측 버튼 또는 상단 목차: 원하는 페이지 이동
- 원본 확대보기: 원본의 표와 세부 문구 확인, ESC로 닫기
- 브라우저 인쇄: 슬라이드별 출력

## 구성
원본 26페이지에 대응하는 재디자인 슬라이드 26장과 추가 슬라이드 4장, 총 30장입니다.
보고서 수집 체계, 데이터 워크플로, 보고서 구성 예시, Claude 연계 소재 피로도 검수를 추가했습니다.
원본에 포함된 수치, 과거 매체명, 파트너십, 지원 조건 및 멤버 정보는 원본 기준입니다.
브랜드스토어는 외부 열람 제한으로 공식몰 https://www.mo-vita.co.kr/ 의 로고와 브랜드 이미지에서 크림/베이지/브라운 톤을 적용했습니다. 공식 CI 색상 코드의 확정본은 아닙니다.
원본의 일부 회사명 오기(홈앤힐)를 모비타로 정리했고 띄어쓰기/표현을 다듬었습니다. 상세 원문은 각 원본 확대보기와 PDF에 보존했습니다.
META 자동 보고서와 소재 피로도 검수는 운영 제안이며 실제 API/커넥터 연결 기능을 이 정적 웹파일에 구현한 것은 아닙니다. 계정 권한, 데이터 가용성, 정기 실행 환경 확인 후 구축합니다.
소스/스타일: index.html에서 수정할 수 있습니다. 이미지 파일을 함께 유지하세요.
